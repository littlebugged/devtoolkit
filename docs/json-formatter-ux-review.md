## 三、隐私安全问题（最严重）

页面底部声明："All tools run in your browser — no data is sent to any server."

**实测通过 CDP 发现加载了以下第三方脚本：**

| 域名 | 类型 | 风险 |
|------|------|------|
| `highperformanceformat.com` | 广告网络脚本（×3） | 可读取页面 DOM |
| `effectivecpmnetwork.com` | CPM 广告网络（×2） | 可追踪用户行为 |
| `cloudflareinsights.com` | Cloudflare 分析 | 行为数据收集 |
| `cdn-cgi/rum` | Real User Monitoring | 页面交互监控 |
| `fonts.googleapis.com` | Google 字体 | 通过 referer 暴露来源 |

**结论**：JSON 数据处理确实是纯客户端，但第三方脚本有能力读取页面内容，隐私声明具有误导性。

## 五、详细交互问题清单

### 流程摩擦点

| 步骤 | 期望 | 实际 | 严重程度 |
|------|------|------|----------|
| 粘贴 JSON | 自动格式化或实时预览 | 只更新 "Valid JSON" 标记 | ⚠️ 中 |
| 点 Format | 出结果 + 焦点移到输出 | 出结果但焦点留在按钮 | 低 |
| 看输出 | 完整显示内容 | 240px 高框里 45 行只能看 12 行 | 🔴 高 |
| 复制结果 | 明确 "已复制" 反馈 | Toast 远离操作区 1.5s 消失 | ⚠️ 中 |
| 想回头改输入 | 快速定位修改 | 需要滚动+手动修改+重新 Format | ⚠️ 中 |

### Tree View 问题

- 不能点击节点复制 JSONPath（如 `$.data.users[0].name`）
- 不能搜索/过滤节点
- 没有"全部展开/全部折叠"按钮
- Tree View 是一个**隐式的模式开关**，UI 传达不够清晰

### 缺失的基础功能

- 缩进配置（2/4/Tab）
- 语法高亮（Format 模式输出）
- 行号
- 键盘快捷键
- 文件拖拽上传
- 输出下载
- 大小对比统计

### 竞品关键差异化总结

**JSON Studio 的核心优势：**
- 粘贴即格式化（零操作成本）
- 双面板都有语法高亮 + 行号
- 输出显示文件大小和 key 数量统计
- 20+ 代码转换器（JSON → TypeScript/Go/Java/Python...）
- ⌘K 命令面板，快速跳转任何工具
- "Send to" 功能直接将结果发送到其他工具

**LocalOnly.dev 的核心优势：**
- PWA 可离线使用（飞机/地铁无网环境）
- 明确使用 Web Workers 和虚拟滚动
- 37 个工具涵盖 JSON 全链路 + 通用开发工具
- JSON Statistics 独立分析工具（深度/key 分布/类型统计）
- CSP 策略阻断所有外部连接，可验证安全性

### 对 DevToolKit 的战略启示

1. **短期（追赶基线）**：DevToolKit 当前处于 jsonformatter.org 2020 年的水平，但连它的"修复 JSON"功能都没有
2. **中期（差异化方向）**：如果走隐私路线，必须删除所有广告/追踪脚本；如果走功能路线，需要至少达到 JSON Studio 50%的功能覆盖
3. **长期（定位选择）**：
   - 选择 A：轻量极简路线（像 CloakBin）——做最快最干净的单页工具
   - 选择 B：全栈工具箱路线（像 LocalOnly）——PWA + 离线 + 工具生态
   - 选择 C：开发者生态路线（像 JSON Studio）——代码转换 + Schema + API 集成
